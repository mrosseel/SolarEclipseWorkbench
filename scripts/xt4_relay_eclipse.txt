# X-T4 through the relay — production eclipse script

# Site 41.764N 2.929W 1100 m, 12 August 2026.  C1 17:34:28Z (sun 17.6 deg),
# C2 18:29:13Z (7.4 deg), C3 18:30:56Z, totality 1m43s.  The sun SETS at
# 19:16Z, before fourth contact — there is no C4 to photograph.
#
# Standard commands throughout: the relay is a property of the camera, not of
# the script.  take_picture taps the relay once, take_burst holds it, and
# take_bracket sets each speed over USB between taps; every one of them drains
# the transfer queue afterwards so the 32-frame buffer can never fill.
# Aperture is "-" because the telescope has none the camera can set.
#
# BODY CONFIGURATION, locked before C1 and never touched again:
#   drive dial CH at 15 fps, mechanical shutter, shutter speed dial T,
#   ISO dial C, PC CONNECTION MODE = USB TETHER SHOOTING FIXED,
#   power save OFF, RAW only, manual focus, IS off.
#
# LOAD ORDER: detect the camera, connect the relay (S2=2, S1=1), then load
# this script — commands bind to their devices at load time.
